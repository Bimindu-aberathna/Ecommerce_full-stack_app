Project Review: Required Changes for Industry Standards

Repository: Ecommerce_full-stack_app • Review date: 2026-05-23

Unused or likely-unused files/folders

  • /todo.html is not referenced anywhere (only ignored in .gitignore). Remove or move to docs.
  • /e-commerce_store/Explanations/explanation1.html is not referenced in code. Remove or move to docs.
  • /Back-End/test-3nf.js and /Back-End/test-relationships.js are not referenced. Remove or move to docs.
  • /Back-End/tests/routes/category.test.js is empty. Implement tests or remove the placeholder.

Unused dependencies to remove or relocate

  • Frontend e-commerce_store/package.json: fs, nodemailer, stripe, socket.io-client are not imported anywhere.
  • Backend Back-End/package.json: body-parser, bull, ioredis, socket.io, ejs appear unused. ejs only shows as an unused import in src/routes/product.js.

Documentation and configuration mismatches

  • Root README.md says Next.js 14, React Context, and Fetch API; actual code uses Next.js 15.4.2, Redux Toolkit, and Axios. Update the README.
  • Root README.md says frontend tests run with npm test, but there is no frontend test script. Add tests or update the docs.
  • e-commerce_store/README.md is the default create-next-app README. Replace with project-specific setup and usage docs.
  • Back-End/.env.example references MongoDB and port 3000; actual code uses MySQL and expects variables like DB_HOST, CLIENT_URL, STRIPE_SECRET_KEY, SMTP_USER, and FRONTEND_URL.
  • Back-End/.env.mysql is committed even though it’s an environment file. Convert it to a sample file and keep real values out of the repo.
  • Docs say the server auto-creates tables, but there is no Sequelize sync or migration execution in code. Either implement migrations/sync or update docs.

Backend code issues to address

  • Duplicate registration of /api/users routes in Back-End/src/app.js.
  • Testing middleware test_route is always enabled for /api/auth; remove or gate it behind NODE_ENV. It also logs res.body instead of req.body.
  • Default port in app.js is 3000, while docs and frontend expect 5000. Align the default and docs.
  • Inconsistent naming (src/Services uppercase, FireBaseServicees.js) should be standardized.
  • emailService.js uses Yahoo SMTP but logs “Gmail” and relies on env vars that are not documented.

Frontend quality issues (linting)

  • npm run lint fails with many no-explicit-any errors, unused variables, and missing hook dependencies. Fix to make lint pass.
  • Multiple <img> tags trigger Next.js lint warnings; consider next/image for optimization.

Build/Test/CI standards

  • Backend tests fail because the only test file is empty. Add tests or remove placeholders.
  • Frontend build fails when Google Fonts are unavailable; consider self-hosting fonts with next/font/local or bundling assets.
  • No CI workflows under .github/workflows; add CI to run backend tests and frontend lint/build.
  • Consider adding dependency/vulnerability scanning (e.g., Dependabot) and documenting audit steps.
